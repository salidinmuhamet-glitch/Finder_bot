# Источники данных

| Источник | Состояние | Примечание |
|---|---|---|
| BicoTender | Подключён | HTML-разбор публичных тендерных страниц; разметка источника может меняться. |
| MP.kz | Подключён | HTML-разбор публичных страниц закупок; доступность зависит от сайта. |
| Goszakup.gov.kz | Отключён | Для подключения нужен проверенный официальный API или разрешённый стабильный способ доступа. |
| Samruk-Kazyna | Не подключён | В текущей проверке endpoint вернул HTTP 418; адаптер не считается работающим. |
| 2GIS и сайты организаций | Частичное обогащение | API-адаптер 2GIS не настроен; контакты добавляются только из фактически полученных публичных страниц. |

Радар не должен придумывать отсутствующие БИНы, телефоны, email или сайты. Gemini классифицирует только переданный текст закупки; при исчерпании квоты или ошибке API применяется фильтр по правилам. Запросы ограничены размером пачки из `criteria.json`, а длительная квота 429 не вызывает бессмысленных повторов.

Для просмотра полей и дублей перед записью используйте `bitrix_sync.py` без `--apply`. Реальная синхронизация создаёт лиды со стадией `NEW` и источником «ИИ-поиск».
